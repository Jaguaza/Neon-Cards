# src/shared

🇪🇸 Español (esta sección) · 🇬🇧 [English below](#srcshared-english)

Componentes visuales, mixins y estilos (la estética neón) reutilizados por
más de una tarjeta.

Nada específico de una sola tarjeta debería vivir aquí — si solo lo usa una
tarjeta, se queda dentro de esa tarjeta en `src/cards/<nombre>`.
